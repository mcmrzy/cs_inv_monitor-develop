# 储能 BMS 参数总表

> 依据 `external/储能bms` 固件源码整理（BBM-5K-48P，16 串磷酸铁锂，SH367309 AFE，软件 BMS.001.2.22）。
> 权威定义：`App/kernel/components/public_data/public_data.h`（运行数据）、`App/kernel/components/parameter/parameter.h`（参数区）。
> 运行数据统一按 `get_bms_data(表号, 偏移)` 寻址；"上云"列指当前遥测链路（heartbeat V2 bat[5]+sys）是否带出该字段。

## 6. 告警体系（T11 等级 + T17 保护动作，19 类 × 3 级）

| # | 告警 | 类别 | 保护等级（典型） |
|---|---|---|---|
| 0 | `ALM_CELL_OV` 单体过压 | 充电 | L2 |
| 1 | `ALM_BAT_OV` 总压过高 | 充电 | L2 |
| 2 | `ALM_CHG_OC` 充电过流 | 充电 | L1 |
| 3 | `ALM_CELL_CHG_OT` 充电单体温度过高 | 充电 | L2 |
| 4 | `ALM_CELL_CHG_UT` 充电单体温度过低 | 充电 | L2 |
| 5 | `ALM_CELL_UV` 单体欠压 | 放电 | L2 |
| 6 | `ALM_BAT_UV` 总压过低 | 放电 | L2 |
| 7 | `ALM_DSG_OC` 放电过流 | 放电 | L1 |
| 8 | `ALM_CELL_DSG_OT` 放电单体温度过高 | 放电 | L2 |
| 9 | `ALM_CELL_DSG_UT` 放电单体温度过低 | 放电 | L2 |
| 10 | `ALM_BAT_UC` SOC 过低 | 放电 | 判定表中被注释 |
| 11/12 | `ALM_ENVIR_OT/UT` 环境温度过高/过低 | 共通 | L2 |
| 13/14 | `ALM_PCB_OT/UT` PCB 温度过高/过低 | 共通 | L2 |
| 15/16 | `ALM_MOS_OT/UT` MOS 温度过高/过低 | 共通 | L2 |
| 17 | `ALM_BAT_DV` 压差告警 | 共通 | L2 |
| 18 | `ALM_BAT_DT` 温差告警 | 共通 | L2 |

- 每类告警独立 3 级（0 无/1/2/3），T11 存等级；达保护等级置 T17 保护动作标志；放电类支持充电中自动恢复；3 级触发电池自锁（FAULT_BATTERY_LOCK，需解锁命令）。
- **上云现状**：聚合为 `sys[3] bms_warning`（u16 位图，逆变器侧视图）❌ 无明细。
- 每类阈值参数（PID_ALARM 4000 段）：3 级 × {告警阈值, 告警延时, 恢复阈值, 恢复延时}，共 19×3×4=228 项，PC 485 命令 0x03 可读写。
- 告警历史计数（PID_ALARM_LOG 6000 段）：19×3=57 项。

## 11. 上云对照结论

| 状态 | 字段 |
|---|---|
| ✅ 已上云（heartbeat V2） | 总压、SOC（1%）、电流（±）、充/放电功率、过充标志、`bms_warning` 聚合位图；eng 组累计充放能量（逆变器口径） |
| ⚠️ 可推导 | 电池工作模式（电流符号+SysStatus 位）、充放方向 |
| ❌ BMS 有、链路无 | SOH、剩余/FCC 容量、16 芯电压数组、均衡状态、极值芯压/芯温及位置、压差/温差、4 路温度明细、MOS 状态×4、充放电保护标志、允许充放电流、充电请求电压/电流、风扇转速、告警 3 级明细、故障 32 位明细、满充/满放次数、低功耗/自锁状态 |

> 补数据的最短路径：BMS→ARM 的 LUX/Growatt CAN 帧已含其中大部分（0x355 SOC/SOH/极值芯压、0x359 容量、Growatt 0x314~0x318 芯压/容量/循环数），扩展点在 ARM 采集器寄存器表 + 心跳 additive 新组，见《储能BMS页面设计方案.md》§6。
