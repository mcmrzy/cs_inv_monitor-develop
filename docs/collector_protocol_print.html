1. 协议概述

特性：

  • 接口：USART串口
  • 帧格式：PPP（0x7E定界）
  • 加密：TEA双重加密
  • 校验：CRC32
  • 字节序：小端序
  • 最大帧长：1088字节

串口配置：

  • 波特率：115200 bps
  • 数据位：8位
  • 停止位：1位
  • 校验位：无
  • 流控制：无

2. 帧格式

Header CmdLen CMD Param1 Param2 Data[] CRC32
字段 偏移 大小 描述
Header 0 1B 固定 0xAA
CmdLen 1 2B 总长度，4的倍数
CMD 3 1B 命令类型
Param1 4 2B 起始地址
Param2 6 2B 数据长度
Data[] 8 变长 负载数据
CRC32 Len-4 4B 校验值

3. PPP封装

帧结构： 0x7E + 数据 + 0x7E

转义规则：

原始转义
0x7E0x7D 0x5E
0x7D0x7D 0x5D

接收状态机：

状态值说明
WAITRECEVIE0x00等待接收
ISRCVING0x01正在接收
RCVFINISH0x02接收完成

4. 加密机制

算法：TEA双重加密 | 密钥：128位 | 块大小：64位

流程：原始数据 → 第一次加密(FrameKey) → 生成TempKey → 第二次加密(TempKey) → 附加密钥片段 → PPP封装

// 密钥生成
TempKey[0..1] = FrameKey[0..1];
TempKey[3] = SysTick->VAL;
TempKey[2] = ~TempKey[3];

// 加密
EncryptData(data, FrameKey, len);
EncryptData(data, TempKey, len+8);
memcpy(data+len+8, &TempKey[2], 8);

6.2 可读写数据 (0x00C8-0x00CB)

命令码：0x04(读) / 0x05(写)

地址 名称 描述 单位 说明
0x00C8 CtrlParamAlterTimeL 控制参数修改时间(低16位) - 与0x00C9组合为32位时间戳
0x00C9 CtrlParamAlterTimeH 控制参数修改时间(高16位) - 记录参数最后修改时间
0x00CA UTCL UTC时间(低16位) s 与0x00CB组合为32位UTC时间戳
0x00CB UTCH UTC时间(高16位) s 写入时自动转换为RTC时间(考虑时区)
UTC时间写入逻辑：
  • 接收到UTC时间后，根据SysParam.TimeZone时区偏移转换为本地时间
  • 与当前系统时间比较，差值 > 4秒时自动校时
  • 调用SetTime()更新RTC

7. 通信流程

读取流程：

  1. 发送读取命令
  2. PPP解封装
  3. TEA双重解密
  4. 校验Header+CRC
  5. 读取参数
  6. 构建响应
  7. 加密并发送

写入流程：

  1. 发送写入命令
  2. PPP解封装
  3. TEA双重解密
  4. 校验Header+CRC
  5. 验证参数范围
  6. 写入EEPROM
  7. 更新DSP参数
  8. 发送状态响应

连接管理：收到有效命令后CollectorConnect=1200，每100ms递减，用于检测采集器在线状态。

8. 错误处理

状态码：

码名称描述
0SUCCESSFUL成功
1CHECK_ERR校验错误
3WAIT_TIMEOUT等待超时
7EXEC_FAIL执行失败

静默丢弃场景：

  • Header ≠ 0xAA
  • CmdLen不合法
  • CRC32校验失败
  • 参数地址越界
  • 参数长度为0或奇数
