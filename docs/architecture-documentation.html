项目概述

CS-INV 是一个企业级的光伏逆变器物联网监控系统，支持万级设备接入、实时数据监控、告警管理、OTA 固件升级等功能。系统采用多服务架构，包含 Go 后端、React 管理后台、Flutter 移动端，通过 MQTT 协议实现设备与服务端的实时通信。

核心功能特性

设备接入与通信

  • BLE 蓝牙配网 - 通过蓝牙低功耗协议配置 WiFi
  • 实时数据采集 - 毫秒级延迟推送至 APP 与管理后台
  • 万级设备接入 - EMQX 共享订阅 + 多实例水平扩展
  • MQTT 协议支持 - 设备状态、遥测、告警数据传输

监控与管理

  • 实时数据监控 - 电压、电流、功率、电量、温度等
  • 告警管理 - 实时告警检测、分级告警、推送通知
  • 电站管理 - 电站分组、设备绑定、发电统计
  • 数据统计 - 图表分析、能量聚合分析

固件升级 (OTA)

  • ARM/ESP 双芯片远程升级
  • MQTT 命令下发 + 进度实时跟踪
  • 升级包管理 - 打包多个芯片固件
  • 本地 OTA - App 通过 WiFi 直连设备升级

用户与权限

  • JWT 认证 - Bearer Token 认证机制
  • RBAC 权限控制 - 基于角色的权限管理
  • 多租户支持 - 代理商→安装商→终端用户层级
  • 设备分享 - 多用户共享同一设备

设计原则

实时数据走 MQTT 直连（低延迟推送），历史/统计数据走 HTTP API（按需查询），安全靠 EMQX 内置 JWT 认证 + 网关层统一鉴权。

安全与认证

JWT 认证机制

系统采用 JWT (JSON Web Token) 进行用户认证，支持 Bearer Token 方式传递。Token 由 API Server 签发，EMQX 验签，确保全链路安全。

认证流程

用户登录
API Server
签发 JWT
客户端存储
请求携带 Token

JWT 配置

# JWT 配置示例 jwt: secret: "your-secret-key" expire_time: 24h # Access Token 过期时间 refresh_expire_time: 168h # Refresh Token 过期时间 issuer: "inv-api-server" audience: "inv-app"

RBAC 权限控制

系统采用基于角色的访问控制 (RBAC)，支持多级权限管理。权限矩阵缓存在 Redis 中，支持数据库回退。

角色定义

角色代码 角色名称 权限范围
0 超级管理员 系统全部权限
1 代理商 下级用户管理、设备管理
2 安装商 设备安装、配置管理
3 终端用户 设备监控、数据查看

权限校验流程

1. API 网关接收请求 2. JWT 中间件验证 Token 3. 提取 user_id、role 等声明 4. RBAC 中间件校验权限 ├── 优先从内存 roleCache 读取 ├── 其次查询 Redis 缓存 └── 最后回源至 PostgreSQL 5. 注入 X-User-ID、X-User-Role 请求头 6. 转发至后端服务

多租户架构

系统通过 parent_id 字段实现层级关系，支持代理商→安装商→终端用户的多级租户架构。每个用户只能访问其下级用户的数据。

服务间认证

内部服务调用使用 X-Internal-Key Header 进行认证，确保服务间通信安全。
