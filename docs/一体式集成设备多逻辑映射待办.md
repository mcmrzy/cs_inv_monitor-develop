# 一体式集成设备多逻辑映射功能待办

## 背景

当前系统有一款三合一集成式逆变器设备，将**逆变器、储能电池、数据采集器**集成在同一个物理设备中：

- 物理上只有一个 SN 号
- 添加设备、绑定电站时只有这一条记录
- 但在电站视图中需要显示为 3 个独立的逻辑设备卡片（逆变器 / 储能 / 采集器）

## 当前状态

- 数据库中只有 1 个设备型号 `CS-I10-6k2`（category = inverter）
- 所有 100 台设备都绑定到此型号
- 设备类型分类已完成：基于 `device_models.category` 精确分类
- 前端已支持 3 种类型：逆变器(purple)、储能(green)、采集器(cyan)

## 待实现方案

### 方案 A：型号多分类字段（推荐）

在 `device_models` 表添加 JSON 数组字段：

```sql
ALTER TABLE device_models ADD COLUMN sub_categories JSONB DEFAULT '["inverter"]';
```

- 三合一型号设置 `sub_categories = ["inverter", "battery", "meter"]`
- 前端根据 `sub_categories` 将一台设备渲染成多张卡片
- 每张卡片从同一份 realtime 数据中提取不同字段

**优点**：改动最小，不需要新增虚拟设备记录
**缺点**：需要前端循环展开逻辑

### 方案 B：虚拟子设备映射表

新建 `device_sub_devices` 表：

```sql
CREATE TABLE device_sub_devices (
  id SERIAL PRIMARY KEY,
  device_sn VARCHAR(64) NOT NULL REFERENCES devices(sn),
  sub_type VARCHAR(20) NOT NULL,  -- 'inverter' | 'battery' | 'meter'
  display_name VARCHAR(100),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

- 物理设备注册时自动创建 3 条子设备记录
- 电站设备列表 API JOIN 子设备表返回多条虚拟记录
- 前端每个子设备显示为独立卡片

**优点**：数据完整性最高，有物理记录
**缺点**：需要新表 + API 改动 + 数据迁移

### 方案 C：纯前端拆分

- 在型号表加 `is_integrated BOOLEAN` 字段
- 前端检测到 `is_integrated = true` 时自动渲染 3 张卡片
- 每张卡片从同一份 realtime 数据中提取不同字段

**优点**：最简单，仅前端改动
**缺点**：后端无法感知子设备结构

## 实施步骤（以方案 A 为例）

### 1. 数据库变更

```sql
ALTER TABLE device_models ADD COLUMN sub_categories JSONB DEFAULT '["inverter"]';
COMMENT ON COLUMN device_models.sub_categories IS '型号支持的子设备类型数组';
```

### 2. 后端 API 修改

- `business-api/internal/model/models.go`：DeviceModel struct 添加 `SubCategories []string`
- `business-api/internal/repository/repositories.go`：查询 device_models 时 SELECT sub_categories
- 设备列表 API 返回时携带 `sub_categories` 字段

### 3. 前端渲染逻辑

- `inv-admin-frontend/src/pages/stations/components/StationDevicesTab.tsx`：
  - 检测到 `sub_categories.length > 1` 时，循环渲染多张卡片
  - 每张卡片显示对应的类型标签和数据
- 逆变器卡片：显示 PV 功率、日发电量
- 储能卡片：显示充放电功率、SOC
- 采集器卡片：显示电表读数

### 4. 型号管理页

- `model_registry_workspace.tsx`：添加"集成类型"多选框
- 创建型号时可选择 `["inverter", "battery", "meter"]`

### 5. 数据迁移

```sql
UPDATE device_models SET sub_categories = '["inverter"]' WHERE category = 'inverter';
UPDATE device_models SET sub_categories = '["battery"]' WHERE category = 'battery';
UPDATE device_models SET sub_categories = '["meter"]' WHERE category = 'meter';
```
