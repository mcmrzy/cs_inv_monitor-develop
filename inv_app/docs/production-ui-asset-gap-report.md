# CSERGY App 生产级 UI / 美术资源缺口审计报告

> 审计日期：2026-08-05  
> 审计范围：`inv_app` Flutter 客户端的真实路由、页面状态、资源目录、Dart 资源引用和深浅色视觉基础  
> 本任务约束：本次只新增本报告，不修改业务代码、SVG、`pubspec.yaml` 或其他文档

## 1. 结论先行

当前 App 的业务页面和主要交互流程已经具备较完整的代码骨架，但**美术资源和生产级视觉验收尚未完成，当前不能判定为“美观完整、可商用交付”**。

主要原因不是缺少页面，而是页面仍以 Material 图标、纯色容器、代码绘制和临时图片为主：

1. 当前 Dart 代码中只有开屏、首页电站卡片和底部导航存在明确的本地美术资源接入；真实逆变器、储能、角色、状态插画和场景资源没有进入生产页面。
2. `assets/icons/csergy/` 已有 24 个 SVG，全部通过 XML、`0 0 24 24` viewBox 和 `currentColor` 校验，但实际代码只使用主导航的 10 个 SVG；其余业务图标和 OTA 导航图标尚未形成页面级接入闭环。
3. 用户提供的真实产品图当前位于 `assets/reference/products/`，只是参考资产，未被页面引用，也没有透明主视图、卡片缩略图、深色背景版本和多尺寸交付规范。
4. 小烁人物、胸前 `CSERGY` 六边形字标、欢迎/成功/提醒/疑问/故障表情和流程插画尚未进入 `assets/`，因此无法支撑开屏、登录、空状态、WiFi、本地模式、OTA 和关于页的统一品牌体验。
5. 深色模式和权限差异仍有生产级风险：底部导航及部分页面 AppBar 使用硬编码白色背景；`RoleService.getNavItems()` 当前始终返回 5 个导航项，没有按权限过滤。

**生产判定：不通过。**  
完成 P0 清单中的品牌/产品资产、状态插画、页面接入、深色模式和角色权限验收后，才能进入商用候选版本。

## 4. 跨页面生产级缺口

### P0：必须先解决，否则无法商用验收

1. **正式品牌资产未锁定**：需要唯一版本的 `CSERGY` wordmark、中文“辰烁科技”（如仍需要）、图形标志、深浅色版本、透明安全区和最小使用尺寸。页面不能继续用文字模拟品牌 Logo。
2. **真实产品素材未生产化**：以用户提供的 CSERGY 逆变器和储能实物为唯一造型源，至少交付透明主视图、列表缩略图、详情 Hero、深色背景版本和 1x/2x/3x 或 WebP 压缩版本；禁止凭空增加不存在的屏幕、端子、侧板、通风结构或颜色。
3. **小烁角色资产未入库**：交付欢迎、成功、提醒、疑问、故障五个基础姿态，以及开屏、WiFi、OTA 完成/失败的扩展姿态；胸前六边形统一使用 `CSERGY`，不得混用中文或其他字样。

## 6. 商用发布门槛

以下任意一项未通过，都不应宣称“美术资源准备完成”或“App 视觉可商用”：

- 正式 `CSERGY` Logo 和真实逆变器/储能产品资产未在关键页面实际显示。
- 开屏、登录、首页、设备、WiFi、本地模式、OTA、关于页仍使用临时图或纯 Material 图标作为主视觉。
- 任意核心流程缺少空态、错误态、加载态、成功态或失败后的恢复动作。
- 深色模式存在白色硬编码背景、低对比度文字、不可见 SVG 或 Dialog/BottomSheet 颜色断层。
- 角色胸前标识不是 `CSERGY`，或同一角色在不同页面出现不同造型、颜色和字标比例。
- 真实产品图出现结构不符、透视错误、比例错误、背景残留或无法区分逆变器与储能。
- 角色权限导致底部导航、空态、操作入口或错误页布局异常。
- 资源只存在于目录但没有真实 Dart 引用、页面截图和真机验收证据。
