## 4. 品牌字标规则

本项目已确认人物服装、产品视觉和 App 产品资产统一使用 `CSERGY`，不在本批产品图中替换为中文名称。

- 产品字标必须使用品牌提供的正式矢量源文件，不使用 AI 重新生成的文字。
- 字标颜色、字距、倾斜角度、比例和安全区必须与品牌源文件一致。
- 不能通过擦除、重绘或锐化方式修复参考图里的字标后直接发布。
- 任何字标不清、变形、锯齿、错字、重复描边或水印覆盖均判定不通过。
- 正式透明母版应保留独立的品牌源文件或可编辑图层，便于后续深色/浅色版本维护。

## 5. 正式透明产品图交付标准

### 5.1 必交文件

每个产品至少需要以下交付物：

1. 2048×2048 透明 PNG 母版。
2. 800×800 产品卡片 WebP 或 PNG。
3. 浅色背景和深色背景预览图。
4. 可编辑源文件或可追溯的 3D/矢量源工程。
5. 正面结构核对图，必要时补充侧面、顶部和背面视图。
6. 产品型号、尺寸、视角、材质、字标和版本说明。

### 5.2 Alpha 与边缘验收

- 文件必须包含真实 Alpha 通道；不得将棋盘格、白底或灰底烘焙进透明图。
- 在纯白、浅灰、深海黑蓝和 CSERGY 蓝背景上检查边缘。
- 不得出现白色抠图边、黑色透明边、半透明毛刺、发光溢出或背景残留。
- 产品底部脚轮、安装件、端子和薄边结构不能被误删。
- 阴影应作为独立可控图层或单独版本交付，不能污染产品本体 Alpha。

### 5.3 色彩与清晰度验收

- 色彩空间使用 sRGB。
- 产品白色外壳不能因过曝丢失轮廓，也不能被渲染成灰色或蓝色。
- 黑色控制区、指示灯和端子细节在深色背景上仍需可辨识。
- `CSERGY` 字标在 800×800 卡片尺寸下必须清晰可读。
- 禁止水印、平台标识、来源不明的第三方标志和嵌入式营销文案。

## 7. 发布门禁

只有同时满足以下条件，产品资产才能从“验收阻塞”变为“可发布”：

- 实物型号、尺寸和结构已由产品负责人确认。
- 正式透明母版已由设计负责人验收，且不带水印。
- `CSERGY` 字标来自正式品牌源文件，不能由 AI 生成或手工临摹。
- 透明 Alpha、边缘、阴影、色彩和不同背景可读性全部通过。
- 逆变器和储能图未混入其他品牌或泛化设备结构。
- 800×800 卡片版本在真实 Flutter 页面中完成真机视觉检查。
- 资产命名、版本号、来源、校验和验收记录齐全。
- 发布资源被放入正式运行时资源目录并由开发任务单独接入；本参考目录仍保持“仅参考”属性。

在上述门禁通过前，任何页面不得使用当前两张参考图作为正式 UI 素材，也不得把它们声明到 Flutter 资源包中。
