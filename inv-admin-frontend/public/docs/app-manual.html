辰烁光伏 App 使用指南

辰烁光伏 App 是您的光伏电站随身助手，支持实时监控、远程控制、固件升级等功能。本文档介绍各功能的使用方法。

一、注册与登录

1.1 手机号登录

1
打开 App，在登录页面输入手机号
2
点击「发送验证码」，收到短信后输入 6 位验证码
3
点击「登录」即可进入系统；首次登录会自动注册账号

1.2 一键登录（推荐）

如果您的手机号支持本机号码认证（移动/联通/电信），可以直接点击「一键登录」按钮，无需输入验证码，速度更快更安全。

忘记密码？本系统使用验证码登录，无需记忆密码。如果收不到验证码，请检查手机号是否正确，或联系客服。

二、电站管理

2.1 创建电站

1
进入「电站」页面，点击右上角 「+ 创建电站」
2
填写电站名称（如"家庭光伏"、"厂房屋顶"）、装机容量、安装地址
3
点击「创建」，然后将设备绑定到该电站

2.2 添加设备到电站

  1. 进入电站详情页，点击「添加设备」
  2. 扫描设备铭牌上的二维码，或手动输入设备序列号（SN）
  3. 确认绑定后，设备即出现在电站设备列表中

三、实时监控

3.1 电站概览

进入电站详情页，可查看：

  • 能量流图：直观展示 光伏板→逆变器→电网/负载/电池 的能量流动方向和实时功率
  • 今日发电：今日累计发电量和收益估算
  • 设备列表：该电站下所有逆变器的运行状态

3.2 设备详情

点击设备可查看详细参数：

数据项说明
直流输入电压/电流光伏板输出的直流电压（V）和电流（A）
交流输出电压/电流/频率并网侧的交流参数
实时功率当前发电功率（kW）
日/月/年/总发电量各时段累计发电量（kWh）
内部温度逆变器内部温度，超过 75°C 会触发高温保护
运行状态正常/待机/故障/离线

3.3 历史数据

在设备详情页切换到「历史数据」标签，可查看：

  • 日视图：当天逐小时功率曲线
  • 月视图：当月每日发电量柱状图
  • 年视图：当年每月发电量柱状图

四、远程控制

对于支持远程控制的设备型号，App 提供以下控制功能：

  • 开关机：远程开启或关闭设备并网
  • 功率限制：设置最大并网功率（适用于限电场景）
  • 时间校准：同步设备时钟
  • 参数配置：调整并网电压上下限、功率因数等（仅专业人员操作）
注意：远程控制操作会记录在操作日志中，供审计和追溯。敏感参数修改需管理员权限。

五、告警通知

5.1 告警级别

级别颜色说明
紧急红色设备故障，需要立即处理
警告橙色异常参数，可能影响发电
信息蓝色状态变更通知，仅供参考

5.2 通知设置

进入「设置 → 消息通知」，可以按告警级别开关推送通知。建议至少开启「紧急」级别通知。

六、固件升级

当设备有新固件可用时，App 会在设备详情页显示升级提示。

  1. 点击「立即升级」按钮
  2. 确认升级后，设备开始下载固件（期间不影响正常发电）
  3. 下载完成后设备自动重启并应用新固件
  4. 升级过程中请勿断电或操作设备
本地 OTA：如果设备网络较差，App 支持通过 WiFi 热点直连设备进行本地固件升级，无需联网。在设备详情页选择「本地升级」即可。

七、个人设置

  • 修改头像/昵称：进入「设置 → 个人资料」
  • 切换语言：支持中文/English
  • 时区设置：调整数据展示的时区
  • 帮助中心：查看文档、FAQ、提交工单
  • 关于我们：查看版本信息、用户协议、隐私政策
使用问题？在 App 内进入「帮助中心」，可查看常见问题或提交工单获取技术支持。
