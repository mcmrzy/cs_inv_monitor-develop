一、下载与安装

1.1 系统要求

平台最低版本推荐版本
Android6.0 (API 23)10.0 及以上
iOS12.015.0 及以上

1.2 下载方式

  • Android：应用商店搜索「辰烁光伏」或扫描官网二维码下载 APK
  • iOS：App Store 搜索「辰烁光伏」下载
权限说明：App 需要以下权限才能正常使用：
• 定位权限：WiFi 配网时扫描附近设备热点、电站位置选择
• 蓝牙权限：BLE 蓝牙配网和本地控制
• 通知权限：接收告警推送和升级提醒
• 相机权限：扫描设备二维码绑定

二、注册与登录

2.1 手机号验证码登录（推荐）

1
打开 App，在登录页面输入手机号
2
点击「发送验证码」，收到短信后输入 6 位验证码
3
点击「登录」即可进入系统；首次登录自动注册账号

2.2 一键登录（运营商认证）

如果您的手机号支持本机号码认证（移动/联通/电信），可直接点击「一键登录」按钮，无需输入验证码，速度更快更安全。

2.3 邮箱登录

海外用户可使用邮箱 + 密码方式登录。

无需记密码：本系统主要使用验证码登录，无需记忆密码。如忘记密码，可通过验证码重置。

标签页面功能

🔌 设备设备列表所有绑定设备、添加设备、设备状态

3.1 首页概览

首页（Dashboard）提供以下信息：

  • 今日发电统计：今日发电量、收益估算、等效减排量
  • 电站卡片：每个电站的实时功率、今日发电、设备在线率
  • 告警摘要：最新未处理告警数量和级别
  • 快速入口：添加设备、扫码绑定、OTA 升级、告警中心

四、电站管理

4.1 创建电站

1
进入「电站」页面，点击右上角 「+ 创建电站」
2
填写电站信息：
  • 电站名称：如"家庭光伏"、"厂房屋顶"、"XX村3号电站"
  • 装机容量：光伏板总功率（kWp）
  • 安装地址：支持地图定位和手动输入
  • 时区：自动根据定位设置，也可手动调整
3
点击「创建」，然后将设备绑定到该电站

4.2 编辑电站

在电站详情页点击「编辑」图标，可修改电站名称、地址、装机容量等信息。

4.3 电站详情

进入电站详情页，可查看：

  • 能量流图：直观展示 光伏板 → 逆变器 → 电网/负载/电池 的能量流动方向和实时功率值
  • 今日发电：累计发电量和收益估算
  • 设备列表：该电站下所有逆变器的运行状态、实时功率
  • 发电趋势：当日逐小时功率曲线
多电站管理：一个账号可创建多个电站，适用于拥有多个安装地点的用户（如代理商、安装商）。

五、设备管理

5.1 添加设备

进入「设备」页面，点击右上角「+ 添加设备」，支持以下方式：

方式说明
自动扫描扫描同一 WiFi 下已配网的设备
扫码绑定扫描设备铭牌上的二维码
手动输入 SN输入设备序列号（16 位）

5.2 设备列表

设备列表展示所有已绑定设备，支持：

  • 状态筛选：在线 / 离线 / 故障 / 全部
  • 排序：按名称、功率、发电量、绑定时间
  • 搜索：按设备名称或 SN 搜索
  • 批量操作：OTA 升级、参数配置

5.3 设备详情

点击设备进入详情页，包含以下标签页：

标签内容
实时数据所有遥测参数实时展示（5 秒刷新）
历史数据日/月/年发电曲线和统计数据
控制远程控制面板（开关机、功率限制等）
告警该设备的告警历史记录
设置设备名称编辑、WiFi 配置、高级设置
OTA固件版本、升级历史、检查更新

5.4 设备信息

在设备详情 → 设置页面可查看：

  • 设备序列号（SN）
  • 设备型号
  • ESP32 固件版本
  • ARM 固件版本
  • WiFi 信号强度（RSSI）
  • IP 地址
  • 绑定时间
  • 运行时长

  • 支持左右滑动切换日期
  • 点击数据点查看精确数值和时间

7.2 月视图

  • 当月每日发电量柱状图

7.3 年视图

  • 当年每月发电量柱状图

  • 支持切换年份
数据精度：历史数据保留 1 分钟粒度（近 7 天），之后自动压缩为 5 分钟 / 1 小时粒度长期存储。

八、远程控制

在设备详情 → 控制标签，可对支持远程控制的设备下发命令。

8.1 基础控制

功能说明操作
开机开启并网输出点击「开机」→ 确认
关机关闭并网输出点击「关机」→ 确认
功率限制设置最大并网功率滑动条设置 → 确认

8.2 储能控制（CS-I10-6K2）

功能说明
充电使能开启/关闭电池充电功能
放电使能开启/关闭电池放电功能
最大充电电流设置充电电流上限（0~60A）
最大放电电流设置放电电流上限（0~120A）

8.3 参数读写

专业用户（安装商/管理员）可通过「参数设置」页面：

  • 读取参数：从设备读取当前配置（并网电压上下限、功率因数等）
  • 写入参数：修改设备运行参数（需管理员权限）
操作安全：
• 所有控制命令均需二次确认
• 敏感参数修改需要管理员权限
• 所有操作记录在操作日志中，可供审计追溯
• 命令执行超时时间为 30 秒

九、告警与通知

9.1 告警中心

在「我的」→「告警中心」或底部导航栏的告警图标，可查看所有告警记录：

  • 按级别筛选：紧急 / 警告 / 信息
  • 按状态筛选：未处理 / 已确认 / 已关闭
  • 按时间范围筛选
  • 支持批量确认和批量关闭

9.2 告警详情

点击告警记录查看详情：

  • 告警设备和设备名称
  • 告警类型和级别
  • 告警时间和持续时长
  • 告警参数值（如电压超限值）
  • 处理状态和处理记录

9.3 通知设置

进入「设置 → 消息通知」，可以：

  • 按告警级别开关推送通知
  • 设置免打扰时段
  • 选择通知方式（App 推送 / 短信）
建议：至少开启「紧急」级别通知，确保设备故障时能第一时间收到提醒。

十、OTA 固件升级

App 的 OTA 中心提供完整的固件升级管理能力。

10.1 OTA 中心入口

在「我的」→「固件升级」或设备详情 → OTA 标签，进入 OTA 中心：

🔍 检查更新

检查所有设备是否有新固件可用，支持一键批量升级

📱 本地升级

WiFi 热点直连设备升级，无需云端网络

📦 固件列表

查看所有可用固件版本和发布说明

📜 升级历史

查看设备升级记录和结果

10.2 远程升级

  1. 在 OTA 中心点击「检查更新」
  2. 系统列出所有可升级设备和对应固件版本
  3. 选择目标设备（支持多选批量升级）
  4. 点击「立即升级」，确认后开始
  5. 设备通过 WiFi 下载固件（不影响发电）
  6. 下载完成后自动重启并应用新固件
  7. 升级进度实时显示在 App 中

10.3 本地升级

适用于设备网络较差或无法联网的场景：

  1. 在 OTA 中心选择「本地升级」
  2. 选择要升级的通道（ESP32 或 ARM）
  3. App 自动连接到设备的 WiFi 热点（CS-INV-XXXX）
  4. 选择本地固件文件或从云端下载
  5. 通过 HTTP 上传固件到设备
  6. 设备接收后自动执行升级
  7. 升级完成后结果自动上报云端

10.4 升级模式

模式说明适用场景
单固件升级仅升级一个芯片（ESP32 或 ARM）个别芯片需要更新
升级包升级打包多个芯片固件，按顺序升级系统性版本更新
本地 OTAWiFi 热点直连升级设备离线 / 网络差
升级注意：
• 升级期间确保设备供电稳定
• 升级过程中请勿操作设备或关闭 App
• 远程升级约需 2~5 分钟，本地升级约需 1~3 分钟
• 升级失败时设备自动回退到上一版本

十一、WiFi 配网

11.1 WiFi 配网

1
长按设备面板 WiFi 按钮 5 秒，WiFi 指示灯快速闪烁
2
在 App「设备」→「+ 添加设备」→「WiFi 配网」
3
App 自动连接设备热点 CS-INV-XXXX
4
输入家中 WiFi 名称和密码
5
点击「开始配置」，等待 30 秒左右
6
WiFi 指示灯常亮表示配网成功

11.2 BLE 蓝牙配网

适用于 iOS 系统或 WiFi 热点连接困难的场景：

1
长按 WiFi 按钮 5 秒进入配网模式
2
App 选择「蓝牙配网」
3
自动扫描附近 BLE 设备
4
选择目标设备（显示 SN 后四位）
5
输入 WiFi 信息，通过 BLE 发送给设备
6
设备连接 WiFi 后自动完成配网

11.3 配网要求

  • 仅支持 2.4GHz WiFi（不支持 5GHz）
  • 支持 WPA/WPA2 加密
  • 不支持需要网页认证的公共 WiFi
  • 手机需开启定位权限（Android）
  • 手机需开启蓝牙权限

11.4 重新配网

更换 WiFi 路由器或密码时，需要重新配网：

  1. 在设备详情 → 设置 → WiFi 配置
  2. 点击「重新配置 WiFi」
  3. 按照配网流程操作

十五、常见问题 FAQ

Q1：收不到验证码怎么办？

  • 检查手机号是否正确
  • 检查短信是否被拦截（查看垃圾短信文件夹）
  • 等待 60 秒后重试
  • 如仍无法收到，联系客服

Q2：设备添加后显示离线？

  • 确认设备已通电且 WiFi 指示灯常亮
  • 检查 WiFi 信号强度（RSSI 应 > -75dBm）
  • 尝试重启设备（断电 30 秒后重新上电）
  • 检查路由器是否正常

Q3：电量数据不更新？

  • 确认设备在线状态
  • 下拉刷新页面
  • 检查网络连接
  • 如持续不更新，提交工单

Q4：如何更换手机？

  • 在新手机上下载 App 并登录同一账号
  • 所有设备和数据自动同步
  • 无需重新绑定设备

Q5：可以多个手机同时登录吗？

  • 支持同一账号在多台设备同时登录
  • 数据实时同步
  • 控制命令会记录操作人信息

Q6：OTA 升级失败怎么办？

  • 升级失败时设备会自动回退到上一版本
  • 检查网络连接后重试
  • 尝试使用本地 OTA 方式升级
  • 如反复失败，提交工单并附上错误截图

Q7：如何解绑设备？

  • 在设备详情 → 设置 → 解绑设备
  • 解绑后设备将从列表中移除
  • 解绑不影响设备运行，可重新绑定
  • 代理商可通过管理后台强制解绑
