光伏逆变器监控系统 — 管理手册

本文档面向系统管理员和组织管理员，介绍后台管理系统的使用方法。

一、角色与权限

系统采用 RBAC 权限模型，按组织层级划分角色：

角色级别主要权限
超级管理员系统级全局管理，含用户、组织、固件、系统配置
代理商渠道级管理下属安装商和终端用户，查看辖区设备
安装商服务商级安装调试设备，管理终端用户
终端用户业主级查看自己的设备和电站数据

1.1 权限说明

  • 上级角色可查看下级的所有数据
  • 终端用户仅可查看自己绑定的设备
  • 权限可按功能模块（设备管理、告警、OTA、工单等）细粒度分配
  • 组织管理员可自定义角色并分配权限

二、设备管理

2.1 设备列表

「设备管理」页面展示您有权限查看的所有设备，支持按状态（在线/离线/故障）、型号、电站等条件筛选。

  • 点击设备进入详情页，查看实时参数、历史数据、告警记录
  • 支持批量操作：固件升级、参数配置、重启等
  • 设备导出：可将设备列表导出为 Excel

2.2 设备型号管理

「型号管理」页面用于管理支持的逆变器型号（如 CS-L10-3K、CS-L10-6K2 等），每种型号定义了：

  • 芯片架构（ESP32/ARM）
  • 支持的通信协议
  • 额定功率范围
  • 远程参数配置模板

三、告警管理

3.1 告警规则

管理员可配置告警触发规则：

  • 设备离线超时（默认 5 分钟无心跳触发）
  • 参数超限（电压、电流、温度等超过设定阈值）
  • 通信异常（MQTT 断连、Kafka 消费延迟）

3.2 告警处理流程

  1. 系统自动生成告警记录并推送给相关人员
  2. 管理员确认告警并指派处理人
  3. 处理人记录处理结果，告警状态变更为「已处理」
  4. 支持批量确认和批量关闭

四、OTA 固件升级

4.1 固件版本管理

在「固件管理」页面可以：

  • 上传新固件（支持 ESP32 和 ARM 双芯片）
  • 查看固件版本历史和发布说明
  • 管理升级包（多个芯片固件打包）

4.2 推送升级

  1. 选择目标固件版本
  2. 选择目标设备（单台或多台批量）
  3. 设置升级时间（立即或定时）
  4. 推送升级命令，设备收到后自动执行
升级注意：OTA 升级期间请确保设备供电稳定。升级失败可能需要本地 USB 刷机恢复。

五、工单管理

「工单管理」用于跟踪和处理用户提交的故障工单和服务请求。

5.1 工单流程

  1. 用户通过 App 提交工单（标题、描述、图片附件）
  2. 管理员审核工单，指派处理人
  3. 处理人解决问题后更新状态为「已解决」
  4. 用户确认后工单关闭

5.2 工单模板

系统内置常用工单模板，帮助用户快速提交：

模板描述默认优先级
设备故障设备运行异常，需要检修高
定期维护设备定期保养维护中
设备巡检设备运行状态巡检低
安装调试设备安装与参数调试中

六、组织架构

「组织架构」管理支持树形层级结构：

  • 创建/编辑组织（代理商、安装商、终端用户）
  • 邀请用户加入组织（通过邀请链接或手机号）
  • 分配组织内角色和权限
  • 查看组织下属的设备和电站

七、操作日志

所有管理操作均记录在「操作日志」中，包括：

  • 用户登录/登出
  • 设备绑定/解绑
  • 远程控制命令
  • OTA 升级记录
  • 权限变更
安全审计：操作日志不可删除，保留 90 天以上。建议定期导出备份。

八、系统监控

「系统监控」页面展示平台运行状态：

  • 服务健康状态（API、数据库、Redis、MQTT）
  • CPU / 内存使用率
  • 数据库连接池状态
  • 版本号和运行时间
