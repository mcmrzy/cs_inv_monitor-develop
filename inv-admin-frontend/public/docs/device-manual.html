一、设备概述与选型

CS-INV 系列逆变器是辰烁能源推出的智能光伏逆变器，支持 WiFi 2.4GHz / 4G 联网，搭载 ESP32-C3 WiFi 通信模块与 ARM 主控芯片（GD32F303 / GD32E230），可通过手机 App 和 Web 管理平台实现远程监控、告警推送、远程控制和 OTA 固件升级。

1.2 系统架构

设备内部由两颗芯片协作：

  • ARM 主控芯片：负责采集光伏输入、电池 BMS、交流输出等实时数据，执行控制命令
  • ESP32-C3 WiFi 模块：通过 UART 与 ARM 通信，负责 WiFi 联网、MQTT 数据上报、BLE 蓝牙配网和本地控制
架构示意：
光伏板 → ARM 主控（数据采集/控制） ⇄ UART ⇄ ESP32 WiFi 模块 ⇄ MQTT/WiFi ⇄ 云端服务器 ⇄ 手机 App / 管理后台

三、安全须知

⚠ 高压危险：本设备工作时存在高压直流（最高 500V DC）和高压交流（220V/230V AC），非专业人员严禁拆机。
  • 安装和接线必须由持有资质证书的专业电工完成
  • 安装前务必断开所有电源（直流侧和交流侧）
  • 严禁在雷雨天气进行安装或接线操作
  • 设备必须可靠接地（PE 线），接地电阻 ≤ 4Ω
  • 严禁将设备安装在易燃易爆环境中
  • 设备运行时外壳温度可能较高，避免长时间触碰
  • 如设备出现冒烟、异味、外壳变形等异常，立即断电并联系售后

四、安装与接线

4.1 安装位置要求

  • 选择通风良好、避免阳光直射的墙壁
  • 设备周围保留至少 20cm 散热空间（上下左右）
  • 安装高度建议离地 1.5m 以上，便于查看显示屏和接线
  • 避免安装在潮湿、多灰尘或腐蚀性气体环境中
  • 安装面应能承受设备重量（约 8~15kg，按型号）

4.2 安装步骤

1
固定壁挂支架：使用膨胀螺丝将支架固定在墙壁上，确保水平、牢固。
2
挂装主机：将逆变器挂在支架上，确认卡扣锁紧。
3
安装天线：将 WiFi 天线拧紧在 SMA 接口上（如未预装）。

4.3 电气接线

接线顺序很重要！请严格按照以下顺序操作，反向操作可能导致设备损坏。

直流侧（PV 输入）

1
确认直流断路器处于 断开 状态
2
将光伏板正极（+）接入 PV+ 端子，负极（-）接入 PV- 端子
3
拧紧端子螺丝（推荐扭矩 2.5 N·m），轻拉确认无松动

交流侧（AC 输出）

1
将电网火线（L）、零线（N）、地线（PE）接入对应端子
2
拧紧端子螺丝（推荐扭矩 3.0 N·m），确认接地可靠

上电顺序

1
先闭合交流侧断路器（AC 开关）
2
再闭合直流侧开关（PV 开关）
3
设备自动启动自检 → 并网 → 开始发电（约需 30~60 秒）
48V 离网型号（CS-I10-6K2）额外接线：还需连接 48V 锂电池组到 BAT+ / BAT- 端子，电池管理系统（BMS）会自动识别。

六、WiFi / 4G 联网配置

6.1 WiFi 配网（推荐）

方式一：App 配网

1
长按设备面板 WiFi 按钮 5 秒，WiFi 指示灯快速闪烁
2
设备创建热点 CS-INV-XXXX（无密码）
3
打开辰烁光伏 App → 「设备」→ 右上角「+ 添加设备」→ 「WiFi 配网」
4
App 自动连接设备热点，输入家中 WiFi 名称和密码，点击「开始配置」
5
等待约 30 秒，WiFi 指示灯变为 常亮 表示配网成功

方式二：BLE 蓝牙配网

适用于 App 无法连接设备热点的场景（如 iOS 系统限制）：

1
长按 WiFi 按钮 5 秒进入配网模式
2
App 选择「蓝牙配网」，自动扫描附近设备
3
选择目标设备（显示 SN 后四位），输入 WiFi 信息并发送
4
配网完成后设备自动连接 WiFi
WiFi 要求：
• 仅支持 2.4GHz 频段（不支持 5GHz）
• 支持 WPA/WPA2 加密，不支持 WEP（已淘汰）
• 建议设备与路由器距离不超过 15 米，中间无承重墙阻隔
• 不支持需要网页认证的公共 WiFi（如酒店、商场）

6.2 4G 联网（可选）

部分型号支持 4G 模块（需另购）：

  • 插入 Nano-SIM 卡（支持移动/联通/电信 4G）
  • 设备自动识别并切换到 4G 联网
  • 4G 模式下流量消耗约 50~100MB/月

七、设备绑定

配网成功后，设备会自动出现在 App 的扫描结果中。

7.1 App 绑定流程

  1. 在 App「设备」页面点击「+ 添加设备」
  2. 系统自动扫描已联网的设备，显示 SN 列表
  3. 选择目标设备，点击「绑定」
  4. 确认后设备即关联到当前账号

7.2 手动输入 SN 绑定

如自动扫描不到，可手动输入设备序列号：

  • SN 印在设备铭牌上，格式如 CS-L10-6K2-XXXXXX 或 H1CNA00135000014
  • 也可扫描铭牌上的二维码自动填入

7.3 绑定规则

  • 一台设备同一时间只能绑定一个账号
  • 如需转移设备，在原账号中「解绑」后重新绑定
  • 支持多用户共享：设备所有者可邀请其他用户查看（只读权限）
  • 代理商/安装商可通过管理后台批量导入设备并分配

十、OTA 固件升级

10.1 远程 OTA（推荐）

当设备有新固件可用时，App 和管理后台会显示升级提示。

  1. 在 App 设备详情页点击「固件升级」或管理后台 OTA 页面推送升级
  2. 选择目标固件版本，确认升级
  3. 设备通过 WiFi 下载固件（期间不影响正常发电）
  4. 下载完成后设备自动重启并应用新固件
  5. 升级过程约 2~5 分钟，请勿断电

10.2 升级模式

模式说明
单固件升级推送单个芯片固件（ESP32 或 ARM）
升级包升级打包多个芯片固件，按顺序逐芯片升级
本地 OTAApp 通过 WiFi 热点直连设备升级（无需云端）

10.3 本地 OTA（离线升级）

当设备网络较差或无法联网时，可通过 App 本地升级：

  1. 在 App 选择「本地升级」
  2. App 连接到设备的 WiFi 热点（CS-INV-XXXX）
  3. 通过 HTTP 直连上传固件到设备（http://192.168.4.1）
  4. 设备接收固件后自动执行升级
  5. 升级完成后上报结果到云端
升级注意：
• 升级期间确保设备供电稳定，断电可能导致固件损坏
• 升级失败时设备会自动回退到上一版本
• 严重故障需通过 USB 本地刷机恢复

十一、常见故障排查

11.1 设备离线

现象：App 显示设备离线，无法获取实时数据。

排查步骤：

  1. 检查设备电源指示灯是否亮起（不亮则检查电源和断路器）
  2. 检查 WiFi 指示灯状态：
    • 常亮 → WiFi 正常，可能是服务器问题，稍等重试
    • 慢闪 → 正在连接 WiFi，检查路由器是否正常
    • 不亮 → WiFi 模块异常，尝试重启设备
  3. 检查路由器是否正常工作，WiFi 信号是否覆盖设备位置
  4. 尝试重启路由器和设备（断电 30 秒后重新上电）
  5. 如仍无法恢复，重新配网

11.2 发电量异常偏低

可能原因：

  • 光伏板表面积灰、树叶遮挡 → 清洁光伏板
  • 连续阴雨天气 → 属正常现象
  • 部分光伏板损坏或接线松动 → 联系安装商检查
  • 逆变器限功率保护（电网电压过高） → 等待电网恢复正常
  • 直流侧电压过低 → 检查光伏板串联数量是否满足最低启动电压

十三、保养与维护

  • 光伏板清洁：建议每季度清洁一次（灰尘较多地区每月一次），使用清水和软布，避免硬物刮擦
  • 接线检查：每半年检查一次设备接线端子是否松动、氧化
  • 散热维护：定期清理设备通风口灰尘，确保散热良好
  • 防雷检查：雷雨季节前检查防雷接地是否完好
  • 长期停机：如需长时间停机（如冬季），建议断开直流侧开关，保留交流侧连接以维持 WiFi 在线
  • 全面检测：设备运行 3 年以上建议联系专业人员进行全面检测
