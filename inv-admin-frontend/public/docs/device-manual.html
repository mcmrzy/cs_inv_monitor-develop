光伏逆变器设备使用说明书

本文档介绍 CS-INV 系列光伏逆变器设备的安装、配置与日常使用方法。

一、设备概述

CS-INV 系列逆变器是辰烁能源推出的智能光伏并网逆变器，支持 WiFi/4G 联网，可通过手机 App 远程监控发电数据、运行状态和告警信息。

参数说明
额定功率3kW / 5kW / 6kW / 10kW（按型号）
输入电压范围80V ~ 500V DC
输出电压220V / 230V AC（可配置）
通信方式WiFi 2.4GHz / 4G（可选）
防护等级IP65（户外安装）
工作温度-25°C ~ +60°C

二、安装与接线

安全警告：安装和接线必须由持有资质证书的专业电工完成。安装前务必断开所有电源。

2.1 安装位置要求

  • 选择通风良好、避免阳光直射的墙壁
  • 设备周围保留至少 20cm 散热空间
  • 安装高度建议离地 1.5m 以上，便于查看显示屏
  • 避免安装在潮湿、多灰尘或易燃环境中

2.2 电气接线顺序

1
直流侧（PV）：将光伏板正极（+）接 PV+，负极（-）接 PV-，拧紧端子螺丝（扭矩 2.5N·m）。
2
交流侧（AC）：将电网火线（L）、零线（N）、地线（PE）接入对应端子，确保接地可靠。
3
合闸上电：先闭合交流侧断路器，再闭合直流侧开关。设备将自动启动自检并网。

三、WiFi 配网

设备首次使用或更换 WiFi 网络时，需要通过 App 进行配网操作。

3.1 进入配网模式

  1. 长按设备面板上的 WiFi 按钮 5 秒，WiFi 指示灯快速闪烁（约 2 次/秒）
  2. 此时设备会创建一个名为 CS-INV-XXXX 的 WiFi 热点（无密码）

3.2 App 配网步骤

1
打开辰烁光伏 App，进入「设备」页面，点击右上角 「+ 添加设备」
2
选择「WiFi 配网」，App 会自动扫描设备热点并连接
3
输入家中 WiFi 名称和密码，点击「开始配置」
4
等待 30 秒左右，WiFi 指示灯变为常亮表示配网成功
提示：配网过程中请保持手机靠近设备（3米以内），确保 WiFi 信号稳定。如果配网失败，请重试或更换 2.4GHz WiFi 网络。

四、设备绑定

配网成功后，设备会自动出现在 App 的「扫描结果」中，点击绑定即可将设备关联到您的账号。

  • 每台设备有唯一的 序列号（SN），印在设备铭牌上，格式如 CS-L10-6K2-XXXXXX
  • 一台设备同一时间只能绑定一个账号；如需转移，请先在原账号中解绑
  • 代理商/安装商可通过管理后台批量导入设备并分配给用户

五、日常监控

5.1 实时数据

绑定成功后，在 App「电站」页面可查看：

  • 发电功率：当前光伏板实时发电功率（kW）
  • 日发电量：今日累计发电量（kWh）
  • 总发电量：设备安装以来累计发电量
  • 并网电压/电流：交流侧实时参数
  • 温度：设备内部温度

5.2 设备状态指示

指示灯状态含义
运行（绿色）常亮正常并网发电中
运行（绿色）慢闪待机（夜间或光照不足）
故障（红色）常亮/闪烁设备故障，需检查
WiFi（蓝色）常亮网络连接正常
WiFi（蓝色）闪烁正在连接网络或配网模式

六、常见故障排查

6.1 设备离线

现象：App 显示设备离线，无法获取实时数据。

排查步骤：

  1. 检查设备电源指示灯是否亮起（不亮则检查电源和断路器）
  2. 检查路由器是否正常工作，WiFi 信号是否覆盖设备位置
  3. 尝试重启路由器和设备（断电 30 秒后重新上电）
  4. 如仍无法恢复，在 App 中重新配网

6.2 发电量异常偏低

可能原因：

  • 光伏板表面积灰、树叶遮挡 → 清洁光伏板
  • 连续阴雨天气 → 属正常现象
  • 部分光伏板损坏或接线松动 → 联系安装商检查
  • 逆变器限功率保护（电网电压过高） → 等待电网恢复正常

6.3 设备报警

当设备出现故障告警时，App 会推送通知。常见告警及处理方式：

告警代码含义处理方式
E001电网过压等待电网恢复正常；频繁出现请联系供电局
E002电网欠压检查电网电压；检查交流侧接线是否松动
E003过温保护检查设备散热环境；清理通风口灰尘
E004绝缘阻抗低检查光伏板接线和接地；可能受潮
E005漏电流过大检查光伏板和线路绝缘；联系售后
如以上方法均无法解决问题：请通过 App「帮助中心 → 我的工单」提交故障工单，或拨打客服热线 400-888-8888（工作日 9:00-18:00）。

七、保养建议

  • 定期清洁光伏板表面（建议每季度一次，灰尘较多地区每月一次）
  • 定期检查设备接线端子是否松动
  • 雷雨季节前检查防雷接地是否完好
  • 设备运行 3 年以上建议联系专业人员进行全面检测
